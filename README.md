# Spacetime from the least mathematics

Author: Michaël Perreault

A beginner text on one formula, three number planes and what they build. It needs school algebra and a little patience. Nothing in it is a new result: every result is known and credited to its authors where it appears, and a list of works with identifiers closes the text.

DOI: [10.5281/zenodo.24596477](https://doi.org/10.5281/zenodo.24596477)
